28 exemplos de A-Frame

Escolhe um exemplo e segue a instrução no ecrã.

  1. Alongpath — Uma esfera segue um caminho. Observa uma volta completa.
  2. Animation — O cubo roda sozinho. Observa a rotação.
  3. Crawling Cursor — Arrasta o rato. O cursor acompanha a superfície dos objetos.
  4. Environment — Arrasta o rato para explorar a floresta.
  5. Event Set — Centra a mira no cubo e clica para o tornar verde.
  6. Extras: Grid — O chão tem uma grelha. Usa W e S para avançar e recuar.
  7. Extras: Json Model — A pirâmide é carregada de um ficheiro JSON.
  8. Extras: Object Model — O objeto tubular é carregado de um ficheiro JSON.
  9. Extras: Ocean — Observa as ondas da água.
  10. Extras: Tube — O tubo passa por vários pontos e forma uma curva.
  11. Forcegraph — Observa os pontos e as linhas a ajustarem as suas posições.
  12. Layout — Cinco esferas ficam distribuídas em círculo.
  13. Lerp — A esfera move-se suavemente de um lado para o outro.
  14. Line — Três linhas formam um triângulo.
  15. Log — Clica no botão para acrescentar uma mensagem ao painel.
  16. Metronome — As esferas acendem à vez, a um ritmo regular.
  17. Mountain — Arrasta o rato para observar o terreno montanhoso.
  18. Outline — Observa os contornos do cubo e da esfera.
  19. Particle System — Observa os flocos de neve a cair.
  20. Physics System — O cubo cai na plataforma. Clica em Recomeçar para repetir.
  21. Point — Observa os três pontos de tamanhos diferentes.
  22. Rain — Observa a chuva a cair à volta do cubo.
  23. Room — Usa W para atravessar a porta entre as duas salas.
  24. Shake2show — Clica na cena para mostrar ou esconder o painel.
  25. Slice9 — Os dois painéis usam a mesma imagem com larguras diferentes.
  26. Spritesheet — Quatro imagens alternadas fazem a bola parecer saltar.
  27. Stereo — Clica no botão para alternar entre a esfera e o cubo.
  28. Text Geometry — O texto tem espessura. Usa A e D para o observar de lado.
